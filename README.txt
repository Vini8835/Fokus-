FOKUS – iPhone PWA

Diese Version läuft als Web-App und kann auf dem iPhone über Safari zum Home-Bildschirm hinzugefügt werden.

WICHTIG:
- Für GitHub Pages muss die Datei index.html im veröffentlichten Verzeichnis liegen.
- Die App speichert Daten lokal im Browser (localStorage).
- Die Website selbst ist bei GitHub Pages öffentlich erreichbar. Persönliche Daten werden nicht an einen Server übertragen.

GitHub Pages:
1. Repository erstellen, z.B. "fokus-app".
2. Diese drei Dateien hochladen: index.html, manifest.webmanifest, README.txt.
3. Settings -> Pages.
4. Source: Deploy from a branch.
5. Branch: main, Folder: / (root).
6. Save.
7. Nach der Veröffentlichung "Visit site" öffnen.
